## 5. Расхождения с заданием, риски и долги

- Распознавание запускается явно отдельной кнопкой после загрузки, чтобы контролировать ограниченный синтетический допуск. Автоматическая очередь любых загруженных документов не включена.
- Кандидаты ищутся среди участников текущего тендера. Если поставщика нет, нужно вручную создать/выбрать участника прежним механизмом; ИИ не создаёт компанию и не подтверждает контакт.
- В файловом store пока один хост/один API worker, до 5000 заданий и 100 записей списка, без пагинации/retention. Нужны backup вместе с originals, ACL, мониторинг ёмкости; повреждённые файлы — восстановление из backup. Редкое повторное использование PID может потребовать проверки зависшей блокировки.
- Worker limits не являются ОС-песочницей и не ограничивают всю native-память. Изоляция/AV/серверный сетевой контроль — ИТ/ИБ. ZIP из TASK-005B остаётся открытым; ограниченный XLSX container не означает разрешение произвольных ZIP КП.
- До 20 MiB/10 страниц; LLM до 30000 символов; XLSX только буквальные значения без формул/внешних ссылок/форматирования дат. Неизвестные данные требуют человека. Плотные/русскоязычные документы и нагрузка не оценены.
- Два английских синтетических PDF и один перечень ТЗ — ограниченный gold set. Порог точности/времени, расширенный корпус и допуск реальных оригиналов — открытая часть Gate D, не блокер разрешённых B/C. Качество по произвольным документам не заявляется.
- TASK-007 сохранён базой отдельного PR; merge ни одной ветки не выполнялся.

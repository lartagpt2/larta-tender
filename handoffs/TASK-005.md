### API и ограничения

- `POST /api/tenders/:id/offers/batches`: обязательный UUID Idempotency-Key; multipart-поле files; до 10 файлов, 20 MiB на файл, 40 MiB на пакет. Ответ содержит batchId и outcomes с индексом, исходным именем, статусом, кодом отказа или ID сохранённых документов. Неверный формат отдельного файла не препятствует сохранению остальных; нарушение транспортных лимитов отклоняет запрос целиком.
- `GET /api/tenders/:id/offers`: реестр с supplierId/supplierName, email, associationStatus, parentId, stage, revision.
- `GET /api/tenders/:id/suppliers`: известные поставщики данного тендера.
- `GET /api/tenders/:id/offers/:documentId/original`: защищённый download с nosniff и attachment, без системного пути.
- `PATCH /api/tenders/:id/offers/:documentId/association`: revision, supplierId (UUID либо null), непустое note до 1000 символов. Наблюдателю запись запрещена; устаревшая revision даёт 409; постороннему — 404.
- Полный SHA-256 манифест пакета включает порядок файлов, имя, MIME и SHA содержимого. Повтор того же ключа/пакета идемпотентен; изменение пакета при том же ключе даёт 409. Конкурентный одинаковый пакет проверен.
- EML: CRLF, MIME-Version 1.0, text/plain или text/html либо одноуровневый multipart/mixed с quoted boundary; вложения с quoted filename и base64. До 20 MIME-частей, заголовки до 32 KiB; вложенные EML/ZIP и неподдерживаемые структуры отклоняются. HTML не отображается и не исполняется. RFC2231/2047, quoted-printable и произвольная вложенность не реализованы.
- From — источник адреса, а не проверка подлинности отправителя. Только единственное совпадение с verified contact данного тендера даёт candidate. Требуется ручное подтверждение; неоднозначность остаётся unresolved. Email из имени/домена файла не придумывается.
- XLSX: проверяются ZIP-сигнатура, центральный каталог и локальные имена, базовые OOXML-записи, лимиты числа/размеров/соотношения сжатия, traversal, шифрование и вложенные исполняемые контейнеры. XML не распаковывается и не анализируется; проверка метаданных не является полным валидатором OOXML/CRC или антивирусом.

## 5. Расхождения с заданием, риски и долги

- ZIP не распаковывается; любые ZIP, включая traversal/bomb, отклоняются и аудируются. Требуется утверждённый обработчик для будущего включения. Распаковка под видом XLSX также не выполняется.
- EML поддерживается только в описанном подмножестве. Согласование полного корпоративного MIME-парсера с ИТ/ИБ не имитируется.
- OCR/LLM, распознавание цен, самостоятельное создание поставщиков, полноценный экран проверки КП и назначения этапов не входят в эту реализацию. Реестр показывает существующий этап, если он задан в данных.
- «Уточнить» меняет выбранный документ. Если требуется перенос всех вложений письма на другого поставщика, уточните каждый файл; массовое подтверждение связей пока отсутствует. Дедупликация сохраняет первый оригинал и его метаданные; повторная встреча тех же байтов не создаёт новый документ, связь attachment сохраняется отдельно.
- Справочник для уточнения содержит уже связанных с тендером поставщиков; экран добавления нового поставщика в этой задаче не создавался.
- Для локальной среды сохранены dev actor/token и запрет data access в production. Корпоративные SSO/RBAC, антивирусный шлюз, ОС-изоляция, нагрузочные лимиты на совокупность параллельных пользователей, фоновая очередь и пагинация реестра требуют последующих решений. Локальная проверка не является допуском к продуктивным конфиденциальным документам.
- Реальные корпоративные КП не предоставлялись и не тестировались. Исходники/КП не отправлялись внешним моделям; публикация кода выполнена только в ранее разрешённый GitHub-репозиторий.

## 6. Инструкции для ручной проверки закупщиком

1. Открыть http://127.0.0.1:5173/tenders и создать либо открыть тестовый тендер. ТЗ можно пропустить.
2. В секции «Коммерческие предложения» выбрать три разных синтетических PDF/TXT, нажать «Загрузить КП».
3. Повторить с ещё четырьмя отличающимися файлами. Убедиться, что отображаются 7 файлов. Перезагрузить страницу: документы должны сохраниться.
4. Загрузить те же файлы повторно: число записей не увеличивается. Скачать оригинал и сравнить с исходным.
5. Открыть группу «Поставщик не определён»: неизвестный email отображается как «Не указан». Никакие цены/поля КП не выдаются за распознанные.
6. Загрузить простой EML указанного выше формата с синтетическим PDF-вложением: письмо и приложение отображаются отдельно. При verified contact связь только предварительная.
7. Нажать «Уточнить», выбрать существующего поставщика либо оставить неопределённого, указать основание и подтвердить. Перезагрузить страницу и проверить связь. Оригинал остаётся прежним.
8. Загрузить ZIP вместе с допустимым TXT: ZIP должен быть отклонён с понятной причиной, TXT сохранён. Проверить ограничения числа/размеров файлов.

Для запуска: из корня рабочей области загрузить tools/enter-workspace.ps1; в tender-platform выполнить npm run dev:api и npm run dev:web в двух терминалах. Постоянная Windows-служба не устанавливалась.

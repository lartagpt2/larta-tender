### Артикулы

Скелет символов используется только для поиска кандидатов. `rawValue`, `value`,
оригинальный PDF и подтверждённые значения не исправляются. Цифры и разделители
должны совпасть; разные цифры не считаются похожими. Несколько подходящих позиций
показываются как варианты. Сам выбор кандидата не переносит цену и не меняет ТЗ.
Checkbox подтверждения требуется для предлагаемого сопоставления; после изменения
документа/поступления/поставщика/лота/состава ТЗ подтверждение сбрасывается.

При переносе форма ещё раз проверяет кандидата, количество, единицу, пустую цену
и совпадение известной валюты строки с выбранной валютой формы. В `sourceNote`
сохраняется основание ручного действия; связь с целевой позицией хранится обычным
`lotItemId` в snapshot проверки. Сохранение AI-черновика не создаёт OfferVersion.
Окончательное подтверждение КП остаётся отдельным существующим действием закупщика.

### Валюта и источник

Принимаются явные ISO-подобные коды в заголовках «Валюта предложения/документа/КП»
и колонках «Цена/Сумма, CODE». Для документа допустим заголовок на другой странице;
локальный заголовок таблицы действует только на той же странице, до итога/границы.
При конфликте явно напечатанных кодов наследование блокируется. Проверенная
непосредственная валюта строки сохраняется. По умолчанию RUB не подставляется.

`currencySource`: scope документа/таблицы, code, sourceDocumentId, page, line,
точный excerpt и rowPage/rowLine. Сохраняется первоначальный rawValue, включая null,
и исходный row snippet. Данные после привязки по-прежнему являются черновиком.
Неизвестный код сохраняется с warning; в бизнес-форму он автоматически не переносится.
Для сканов доверенное наследование не выполняется: нужен проверяемый текстовый
слой; распознанные vision значения остаются с `vision_evidence_requires_review`.

Промпт **untrusted-compact-evidence-v3** и модель не изменялись. Новая версия схемы
входит в ключ job: старые завершённые результаты доступны, повтор выполняется
явно отдельным job. Старые pending jobs другой схемы получают configuration_changed,
требуют явного повторного запуска и не подменяются молча.

3. Посмотреть оригинальное написание и Unicode артикулов. Выбрать предложенную

4. Проверить количество/единицу, цену и валюту формы. Попытка переноса при другой

5. Раскрыть источник валюты: проверить документ, страницу/строку заголовка,

6. Сохранить AI-черновик и убедиться, что сравнение/цены не изменились. Окончательное

## 5. Ошибки, ограничения и рекомендации

### A. Валюта из общего контекста не проходит evidence строки

В f02 четыре строки имеют числа без повторения RUB, но общий заголовок явно задаёт

Рекомендация для отдельной доработки: проверяемая ссылка строки на валюту общего
заголовка в пределах документа/таблицы; никаких предположений RUB по умолчанию
и ослабления evidence для произвольного текста. В TASK-008F это не реализовано.

### B. Омоглифы в артикуле скана

Эталон `Энкодер СО-981`, `Втулка СО-982` (кириллица U+0421/U+041E), модель
вернула `Энкодер CO-981`, `Втулка CO-982` (латиница U+0043/U+004F).
Шрифт делает символы визуально неотличимыми; алфавит нельзя надёжно восстановить
только по этим пикселям. Две строки не сопоставились строго: 14 полевых ошибок
и 2 unmatched-row записи; фактические числа/валюты/сроки в обеих строках верны.
Рекомендация: сохранять исходное написание, подсвечивать неоднозначные артикулы,
предлагать кандидатов из справочника только для подтверждения закупщиком.
Не заменять алфавит автоматически: разные реальные артикулы могут смешаться.
Критерий эквивалентности для будущего набора согласовать ДО нового прогона;
текущие эталоны и первичные результаты остаются строгими.

Заранее предложенный ориентир: каждое критичное поле >=98%, поставщик/ИНН 100%,

FIFO. Четыре поля ниже 98%; дополнительно проблема связи валюты с ценой. Ориентир

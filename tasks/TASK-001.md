# TASK-001 — Аудит готовой среды и репозитория (без изменений БД)

**Приоритет:** P0. **Основание:** README, AGENTS.md, docs/PLAN.md. **Результат:** `handoffs/TASK-001.md`.

## Задача

Подтвердить фактическое состояние уже развёрнутого окружения для Larta Tender; не создавать второй проект и не переустанавливать существующие инструменты.

## Действия

1. Проверить, что текущий путь внутри утверждённой рабочей области; вывести `git rev-parse --show-toplevel`, адрес remote (без токенов), branch, `git status --short`, структуру каталогов и наличие `AGENTS.md`.
2. Просмотреть `package.json`, lockfile, конфигурации Vue/NestJS, тестов, миграций и CI **без запуска мутирующих команд**. Отметить, чего не хватает против заданного стека.
3. Проверить доступность PostgreSQL **без вывода секретов**; запросить подтверждение владельца, какую пустую тестовую БД/роль разрешено использовать. Разрешены проверка версии/портов/конфигурации подключения без SQL-записей, только если это допустимо в выделенной среде.
4. Проверить, находится ли Ollama в зоне доступа приложения, без скачивания моделей/вызова на реальных документах.
5. Осмотреть и перечислить разрешённые MCP и GitHub workflow без установки/расширения прав.
6. Сопоставить наблюдения с `docs/PLAN.md`, составить таблицу «проверено / отсутствует / требует решения» и предложить безопасный TASK-002 scope.

## Запрещено

Создавать/удалять БД, менять роли/пароли, делать миграции, скачивать модель/новые MCP, пушить в `main`, переписывать структуру без отдельного задания.

## Критерии приёмки

- [ ] Факты с командами и результатами; неизвестное помечено «не проверено».
- [ ] Список всех найденных рисков и конкретных вопросов владельцу, без секретов.
- [ ] Handoff содержит рабочие версии инструментов и готовность тестов/CI.

# TASK-006 — Верификация полей, расходы и сравнительная таблица

**Зависимость:** принято TASK-005. **Прототип:** S04 и S05.

## Задача

Реализовать экран проверки КП и серверный расчёт сравнимой стоимости по лоту либо по каждой позиции. LLM не требуется для ручного сценария.

## Состав

- Предложение с исходными значениями и отдельно подтверждаемыми значениями; ручной источник `document/phone/email/other` + комментарий, автор, дата.
- Кнопка «Сохранить и подтвердить»: проверка всех обязательных полей, очистка только разрешённых замечаний; сохранить статус «Есть вопросы», если осталось иное замечание.
- Транспонированная таблица с акцентами: цена исходная, актуальная, оплата, срок, соответствие, аккредитация (пока «Нет проверки»), дополнительные расходы.
- Галочка для ввода расходов вручную, статусы `included/add/unknown`, расчёты с Decimal; цена не учитывает неизвестный расход как ноль.
- Валидация валют/НДС/единиц, отсутствие рейтинга неполных лотов. Экспорт CSV с теми же значениями и атрибуцией.

## Приёмка

- [ ] Тест «срок 7 дней после звонка»: ручное значение сохраняется, проверка обновляется корректно.
- [ ] Таблица транспонирована; лот и позиции переключаются, исходная цена не переписывается.
- [ ] Все арифметические и пограничные случаи из `docs/ACCEPTANCE.md` проходят в Jest.

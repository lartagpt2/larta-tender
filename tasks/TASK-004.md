# TASK-004 — Тендер, позиции, ТЗ и пропуск загрузки

**Зависимость:** принято TASK-003. **Прототип:** S01, S02, S03.

## Задача

Реализовать на реальных API/БД список и создание тендеров тремя путями: вручную (одна/несколько позиций с количеством), через ТЗ, только название. Не имитировать OCR.

## Состав

- Vue формы с Zod/VeeValidate, сохранение в PostgreSQL через NestJS и обновление TanStack Query.
- Режим «по лоту / по позициям»; при отсутствии позиций — объяснять причину недоступности построчного режима.
- Отдельный вид черновика ТЗ с явной кнопкой подтверждения, если локальный обработчик доступен; иначе корректный статус «Ожидает обработки».
- «Пропустить и свернуть» → компактный блок; «Загрузить ТЗ позже» раскрывает; общая загрузка КП не блокируется.
- Пустые состояния, мобильная адаптивность и две темы.

## Приёмка

- [ ] Сценарии создания из `docs/ACCEPTANCE.md` проходят на тестовой БД.
- [ ] После перезагрузки браузера данные берутся из backend, не из localStorage демо.
- [ ] Файл ТЗ не помечен как разобранный, если OCR не запускался.

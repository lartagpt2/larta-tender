# TASK-007 — Аккредитация, этапы тендера, переторжка и переписка

**Зависимость:** принято TASK-006. **Прототип:** S05–S07.

## Задача

Сохранить историю аккредитаций и этапов с отдельными документами, отобразить результат в **одной** сравнительной таблице. Подготовить письма как черновики без отправки.

## Состав

- Отчёт аккредитации из отдельного ресурса: файл, компания, дата, статус, примечание, история. Нет отчёта → красный «Нет проверки» в сравнении.
- Типы этапа: уточнение КП, следующий этап с комментарием (например, изменение ТЗ), переторжка. Произвольная последовательность этапов с уникальным номером.
- Для каждого этапа: адресаты из подтверждённых контактов и редактируемые шаблоны; отсутствие email не должно генерировать фиктивный адрес.
- Ответные КП проходят через общий загрузчик, привязываются к этапу и новой `OfferVersion`. Исходная версия не изменяется.
- В сравнении добавляются **новые строки**, не отдельная таблица: стоимость этапа, скидка этапа и общий процент. Нет ответа → предыдущая цена остаётся действующей, снижение 0%, статус ответа сохранён.
- Журнал действий, история файлов/решений, автотесты расчётов и E2E сцен.

## Приёмка

- [ ] Аккредитации и красные пропуски соответствуют реестру отчётов.
- [ ] 100 000 → 95 000 → 90 000 → нет ответа: первоначальное значение сохранено; скидки 5%, ~5,2632%, 0%; общая 10%.
- [ ] Черновики имеют адресатов из источника, но не отправляются автоматически.
- [ ] Приёмка из `docs/ACCEPTANCE.md` пройдена и задокументирована.

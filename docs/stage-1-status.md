## Финальная проверка на каркасе

Граф текущего кода построен: 234 узла, 299 связей. Локальный запрос FileStore вернул 14 связанных узлов. Документы пропущены; необязательный tree-sitter-sql не установлен, поэтому SQL-файл не включён в AST-граф. Это не проверка SQL на PostgreSQL.

Обёртка нормализует расширенные пути Win32 перед проверкой корня. При отказе выбрасывает RuntimeError: PermissionError внутри tempfile на Windows может ошибочно интерпретироваться как коллизия имени и вызывать долгие повторы. Разрешён системный null-device для отброшенного вывода Git — данные на диск вне корня не сохраняются. PYTHONHASHSEED=0 задаётся при загрузке окружения, чтобы Graphify не перезапускал Python в обход обёртки. Self-test проверил расширенный путь, отказ внешней записи и отказ сети. Исключения для служебных файлов заданы в .graphifyignore.

# ADR 001: локальное окружение

Все новые инструменты, зависимости, кэши, браузеры и тестовые данные находятся внутри корня ai_project. Node.js 24 выбран для NestJS 11 и Vite 7. Монорепозиторий использует npm workspaces и один package-lock.json. Для воспроизведения: загрузить tools/enter-workspace.ps1 и выполнить npm ci --ignore-scripts внутри tender-platform.

Техническая изоляция отложена пользователем. Существующий агент и его компоненты за пределами корня не переносились. PostgreSQL и 1С не подключены. Локальный сервер слушает только 127.0.0.1. Подключение к внешним моделям отсутствует.

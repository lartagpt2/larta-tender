## Официальные источники Graphify

- Метаданные пакета: https://pypi.org/pypi/graphifyy/json
- Репозиторий и манифест: https://github.com/Graphify-Labs/graphify/blob/v8/pyproject.toml
- Локальная работа: https://docs.graphify.com/open-source/local-development
- Настройки: https://docs.graphify.com/open-source/configuration/graphifyrc
- Переменные: https://docs.graphify.com/open-source/configuration/environment-variables

Старые адреса graphiffy.com/docs и graphiffy.com/integrations/codex при проверке вернули 502.
Манифест просмотренной ветки требует Python >=3.10 и содержит зависимости с диапазонами версий; он не заменяет lock-файл с хешами.
Согласно описанию пакета, код разбирается локально, а документы и медиа могут использовать модель. Проверка исходников конкретного релиза и сетевого поведения ещё не проведена.
Не считать все режимы Graphify локальными только по описанию.

## Предполагаемые права и пути

- CLI: чтение только tender-platform; окружение tools/graphify-venv; результат tender-platform/graphify-out.
- Кэши Python и pip: cache/python и cache/pip; временные файлы: temp. Перед созданием проверить каждый компонент пути.
- MCP при необходимости: локальный stdio, абсолютный путь интерпретатора, чтение конкретного graph.json; конфигурация mcp/config, журналы mcp/logs.
- На стадии получения зависимостей нужны обращения к официальному реестру и хранилищу артефактов. Перед исполнением проверить артефакты, точные версии, хеши, транзитивные зависимости и установочные действия.
- Исходники, документы и секреты внешним сервисам не передавать. Облачный endpoint и API-ключи не настраивать.
- Не запускать graphify install, graphify codex install, shell installers, глобальный pip, uv tool install и изменение PATH. Пути записи интегратора пока не проверены.
